# Eidolon

[English](README.md) · [Español](README.es.md) · [اردو](README.ur-pk.md)

Eidolon 是 AetherMesh 正在开发的开源桌面代理管理器。项目的方向是让每个代理拥有持续的身份、专属对话，以及能够随协作保留下来的有用上下文。

项目将代理交互、本地数据与协同工作整合到一个应用中。你应当能够回到某个代理、继续对话，并了解它正在做什么，而不必手动管理一组互不关联的会话。

计划中的 `AetherMesh-core` SDK 将把应用连接到 AetherMesh 点对点 AI 网络。Eidolon 希望将其作为可选集成，同时保留现有 AI 提供商、身份验证、凭据、模型路由及其他集成。Nous Portal、OpenRouter、OpenAI 等服务仍属于各自的提供商。这里描述的是项目方向，不是已经验证的网络能力。

> **早期 Alpha / 概念验证。** 请查看 [Eidolon 发布页面](https://github.com/AetherMesh-AI/Eidolon/releases)，了解每个构建的产物、说明、验证范围与限制。发布产物不代表已经适合生产使用，也不代表所有平台都有经过验收的安装程序。

## 我们希望实现的体验

- 以代理为中心，持续保留身份、角色与专属对话。
- 在协作中清楚展示工作归属、已有决定与需要用户参与的事项。
- 保留有用记忆，并有意地共享相关知识，而不是让所有代理读取所有对话。
- 让用户明确控制权限、访问范围与重要操作。
- 可靠地保留对话，并在发生故障后安全恢复。

这些原则指导开发，并不意味着所有记忆、权限或协作机制都已实现或验证。

## 当前基础与限制

桌面应用包含代理对话，以及首页、目标、组织、活动、知识和能力等视图。界面中出现这些视图，不代表已经连接了可执行工作的组织系统。

组织目标、计划、示例团队与结果记录仍是原型。创建目标不会向代理分派工作。示例数据是虚构的；组织记录保存在 `window.localStorage` 中，与正式对话存储分开。界面中的本地批准不授予运行时权限，记录结果也不能证明工作已经执行。

默认应用数据目录是 `~/.eidolon`。有限范围的原生测试验证了启动、应用品牌显示，以及合成对话在重启后的持久化。本地记忆与跨代理记忆仍是原型；首次切换到第二个代理、进程清理、真实 AI 对话流程和完整安装应用验收仍需进一步验证。

基于 Git 的更新使用本项目仓库。macOS Apple Silicon 上的安装应用测试验证了更新后自动重启、保留合成对话，以及在拉取和打包命令失败后恢复。测试使用本地 Git 传输及临时签名、未经公证的应用；不能据此认定模型推理、Windows/Linux 支持或所有中断恢复路径已经通过验收。此初始 Alpha 是源码发布，不承诺经过验收的跨平台二进制安装包。
