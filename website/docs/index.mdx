# Eidolon

Eidolon is an experimental desktop agent manager by AetherMesh, derived from Hermes Agent. It brings persistent agents, objectives and shared skills into one workspace. Organization, delegation and memory screens currently include local prototypes; a displayed assignment or approval does not mean work was executed.

Existing AI providers remain available. AetherMesh-core is planned as an optional SDK connection to the AetherMesh peer-to-peer AI network. That network integration is not implemented by this cleanup.

## Documentation scope

The detailed runtime, tools, provider and extension guides are inherited technical documentation and are being reviewed incrementally for Eidolon. The primary command is `eidolon`, Python imports use `eidolon_cli` and `eidolon_*`, and the default application home is `~/.eidolon`. `EIDOLON_HOME` is the canonical startup override; `HERMES_HOME` remains the internal compatibility transport. Legacy plugin metadata/discovery keys and real provider/model names remain unchanged where required. Upstream hosting, support and release promises in older guides are not Eidolon commitments. Prefer this repository's current README, contributor guide and security policy when they differ.

For the first source update across the package rename, read the [internal-name migration notes](https://github.com/AetherMesh-AI/eidolon/blob/main/docs/internal-name-migration.md). An old `hermes update` process cannot complete that transition.
