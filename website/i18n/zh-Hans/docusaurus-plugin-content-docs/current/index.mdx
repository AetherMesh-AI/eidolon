# Eidolon

Eidolon 是 AetherMesh 开发的实验性桌面智能体管理器，基于 Hermes Agent 代码库。它将持久智能体、目标和共享技能集中在一个工作区。组织、委派和记忆界面目前包含本地原型；界面显示的任务分配或审批并不代表任务已实际执行。

现有 AI 提供商仍可使用。AetherMesh 页面显示“Coming soon”，计划通过可选的 AetherMesh-core SDK 连接 AetherMesh 点对点 AI 网络；该集成尚未实现。

## 文档范围

详细运行时、工具、提供商和扩展指南继承自上游，并逐步适配 Eidolon。主要命令是 `eidolon`，Python 包和模块使用 `eidolon_cli` 和 `eidolon_*`，默认应用目录为 `~/.eidolon`。`EIDOLON_HOME` 是启动时的首选覆盖值，`HERMES_HOME` 保留为内部兼容传递机制。插件兼容字段、真实提供商与模型标识保持原样。

较旧指南中的上游托管、支持和发布承诺并非 Eidolon 的承诺。如有差异，以本仓库当前 README、贡献指南和安全政策为准。
