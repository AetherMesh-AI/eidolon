
## Reviewed TypeScript checks

When the fixed TypeScript execution adapter is available, `project_typecheck` consumes its exact current, independently reviewed compiler receipt, including selected inputs, effective configuration, pinned runtime, and confirmed cleanup. A project-scoped criterion verifies only that selected project; unscoped checks retain the runtime's all-selected-project coverage. Missing, stale, unsupported or different-kind receipts fail closed. Compiler success never satisfies `project_tests`. The single-recipe project adapter cannot combine tests and typecheck for one project in the same latest run. `project_build` consumes the canonical reviewed run receipt and every generated artifact in its complete verified same-run output manifest. Omitting the receipt or any output cannot satisfy the criterion. Generated bytes remain managed artifacts; they are not source installation or test evidence. Changed output bytes, source, grant or manifest fail closed.
